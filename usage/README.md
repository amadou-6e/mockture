# Usage Demo

Runnable notebooks demonstrating Mockture workflows.

## Notebooks

### `mockture_server_usage.ipynb` — raw `Mockture` server object
Covers the `Mockture` class directly (no pytest plugin):
1. Start a real FastAPI service in the background.
2. Export its OpenAPI spec to YAML.
3. Load templates from `orders.templates.yml`.
4. Demonstrate strict vs non-strict contract validation.
5. Inspect call counts and violations.

### `mockture_plugin_usage.ipynb` — pytest plugin *(planned)*
Covers the pytest plugin layer:
- `pytest_plugins = ["mockture.pytest_plugin"]` activation
- `@pytest.mark.mockture(...)` marker with `contract=`, `templates=`, `flow=`, `scenario=`, `scope=`
- `mockture.ini` per-directory config
- `use_mockture` decorator alias
- Scope pooling (module/session reuse)

## Shared files

- `basic_api.swagger.yml` — generated by the server notebook from `/openapi.json`
- `orders.templates.yml` — templates file used by both notebooks

Run from the repository root so `from example.basic_api import app` resolves correctly.
